# Construction Demo

A multi-page construction company website (home, about, services, features, blog, contact) built with [Astro](https://astro.build) and published with GitHub Pages.

**Live site:** https://mohammedanasfl.github.io/construction-demo/

## Structure

```
src/
  layouts/Base.astro     page shell: <head>, preloader, navbar, footer, scripts
  components/            Navbar, Footer, PageHeader, Hero (scroll reveal), Stats,
                         About, Features, Services, Blog
  pages/                 one file per page (index, about, service, feature, blog, contact)
public/                  static files copied as-is: css/, js/, img/, lib/
docs/                    BUILD OUTPUT, served by GitHub Pages (do not edit by hand)
```

Edit things in `src/` and `public/`. The `docs/` folder is regenerated by `npm run build`.

## Run locally

Requires Node 18.20.8+, 20.3+ or 22+.

```bash
npm install
npm run dev        # http://localhost:4321
```

## Build and publish

```bash
npm run build      # writes the site to docs/
git add -A && git commit -m "..." && git push
```

GitHub Pages is set to **Deploy from a branch** with the **/docs** folder, so a push of the rebuilt `docs/` is all that is needed. `public/.nojekyll` is copied into `docs/` so Pages serves the files as they are.

## Home page hero

`src/components/Hero.astro` + `public/js/modern.js` + `public/css/modern.css`. The hero is pinned while you scroll: a blueprint is wiped by a laser into an under-construction photo, then into the finished building. The three images are `public/img/hero-1-blueprint.jpg`, `hero-2-construction.jpg` and `hero-3-finished.jpg` (keep them the same size and framing if you replace them). With "reduce motion" enabled the hero shows the finished building without pinning.
